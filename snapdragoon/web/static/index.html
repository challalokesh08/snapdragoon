      About & accessibility

      Snapdragoon is built to the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. That is a deliberate response to how often on-device AI demos are inaccessible by default.

      What it does

      • Captions microphone speech entirely on-device, with no network call.
      • Describes what the camera sees, with confidence scores.
      • Runs on CPU via ONNX Runtime, with a Snapdragon NPU path implemented against Qualcomm AI Hub and QNN. The status panel below always states which engine is live and whether it is NPU-accelerated — it will not imply an NPU it is not using.

      Accessibility commitments

      • Captions announce through a polite live region, so they never interrupt.
      • Full transcript history is available to re-read, not only announced live.
      • Every control is a real button, reachable and operable by keyboard alone.
      • A skip link is the first focusable element.
      • Focus is never trapped; visible focus indicators are never suppressed.
      • All text meets at least 4.5:1 contrast; the live region respects reduced motion.

      Known limitations

      • English-only speech recognition.
      • Scene description is whole-image classification, so it will not read text or count objects.
      • The demo engine produces synthetic captions and is clearly labelled as such.

      Full conformance statement: docs/ACCESSIBILITY.md in the repository.
